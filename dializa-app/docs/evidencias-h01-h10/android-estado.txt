Build Android no verificado. Se instalaron NDK y plataformas faltantes con permiso del usuario y se habilito desugaring requerido por el plugin. El intento llego a Gradle, pero el bootstrap flutter.bat ejecuto pub upgrade online y aborto repetidamente con -1073741816 (0xC0000008). Se preparo un snapshot real del SDK mediante su entrypoint Dart. Un intento adicional con USERPROFILE aislado no detecto SDK; se corrigio ANDROID_HOME y el siguiente intento quedo sin salida y se interrumpio al cerrar la verificacion. No se entrega APK ni se declara compilacion exitosa. Repetir flutter build apk --debug --no-pub en una terminal normal con el SDK configurado; el cambio Gradle de desugaring aun necesita una compilacion completa.
